# საკადასტრო გეგმა → KML / SHP

NAPR-ის (საჯარო რეესტრი) საკადასტრო გეგმის PDF-იდან ნაკვეთის კონტურის გადაყვანა KML-სა და Shapefile-ში. მუშაობს მთლიანად ბრაუზერში: ფაილები არსად იგზავნება, ინტერნეტი არ სჭირდება.

**გამოყენება:** გახსენი გვერდი (GitHub Pages) ან `index.html`, ჩააგდე PDF(-ები), მონიშნე და ჩამოტვირთე KML / SHP.

## სტრუქტურა

| გზა | რა არის |
|---|---|
| `index.html` | მზა ხელსაწყო (ერთი ფაილი, pdf.js ჩაშენებული) |
| `tool/core.mjs` | ბირთვი: ვექტორის/ბადის ამოღება, ტრანსფორმაცია, UTM ზონა, რასტრული რეჟიმი, KML/SHP/ZIP |
| `tool/ui.js`, `tool/style.css` | ინტერფეისი |
| `tool/build.mjs` | აწყობა → `tool/dist/` და `index.html` |
| `tool/run_node.mjs` | იგივე ბირთვი Node-ში: `node run_node.mjs <pdf> <outdir>` |
| `tool/batch_test.mjs` | მასობრივი ტესტი: ბევრი PDF (zip-ებიც) → კატეგორიები, ოფიციალურ კონტურთან შედარება, `report.html` / `results.csv` |
| `python/pdf2kml.py` | Python ვერსია (PyMuPDF; JS-ს ჩამორჩება) |
| `plan_reader/` | "საკადასტრო რუკის" PDF-ის ტიპის ამოცნობა (გეგმა / ნახაზი) |

## აწყობა

```
cd tool
npm install
node build.mjs
```

## მასობრივი ტესტი

```
cd tool
node batch_test.mjs <PDF-ების საქაღალდე> <შედეგი> [--ref <ოფიციალური shp/kml/geojson/zip>]
```

თითო PDF-ს ანიჭებს კატეგორიას (`ok`, `ok_notes`, `ok_warnings`, `raster`, `area_mismatch`, `ref_mismatch`, `grid_missing`, `no_boundary`, `not_plan`...). ოფიციალური კონტური შედეგს გეომეტრიით ეწყვილება (IoU, Hausdorff, წანაცვლება). წარუმატებელი PDF-ები კოპირდება `failed/<კატეგორია>/`-ში.

## სიზუსტე

ვექტორული გეგმები, ოფიციალურ shp-სთან შედარებით (9 ნაკვეთი): IoU 0.995–0.999, საშუალო ცდომილება 0.02–0.30 მ, მაქსიმალური 0.04–0.56 მ (მასშტაბზეა დამოკიდებული). რასტრული PDF-ები: დაბალი სიზუსტე, ბარათზე გაფრთხილებით. შედეგი ოფიციალურ shp-ს არ ცვლის.
